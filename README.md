# Family Contract

A [Chickadee Bandit](https://chickadeebandit.com/app-library/family-contract) app.

Parents create step-by-step acknowledgement contracts for kids — watch videos, agree to costs, make commitments — before a big decision like getting a pet or an instrument.

## Features

- Parents create step-by-step contracts.
- Steps can be videos to watch, costs to agree to, or commitments to make.
- Kids acknowledge each step in order.
- A record of what was agreed, for the first time the rule is tested.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-family-contract/releases/latest/download/bundle.json
```
